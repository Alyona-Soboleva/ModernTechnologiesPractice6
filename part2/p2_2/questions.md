# Вопросы по JDBC - Часть 2

## Вопрос 1: LIKE с %

**Вопрос:** Почему используется LIKE с % в `findByTitle`?

**Ваш ответ:**

% - это wildcard символ в SQL LIKE, который означает "любая последовательность символов". Использование % позволяет находить фильмы по частичному совпадению названия:
1) %Матрица - найдет фильмы, которые заканчиваются на "Матрица"
2) Матрица% - найдет фильмы, которые начинаются на "Матрица"
3) %Матрица% - найдет фильмы, содержащие "Матрица" в любом месте названия
В нашем методе findByTitle(conn, "Матрица") мы используем %Матрица%, потому что хотим найти все фильмы, в названии которых встречается слово "Матрица" независимо от его позиции

## Вопрос 2: PreparedStatement vs Statement

**Вопрос:** Что такое PreparedStatement и почему он безопаснее Statement?

**Ваш ответ:**

PreparedStatement - это интерфейс в JDBC, который представляет предварительно скомпилированный SQL-запрос с параметрами. Он безопаснее обычного Statement по нескольким причинам:
1) PreparedStatement автоматически экранирует специальные символы в параметрах, не давая злоумышленникам внедрить вредоносный SQL-код.
2) PreparedStatement один раз компилируется на стороне БД, а затем может многократно выполняться с разными параметрами, что дает прирост производительности.
3) SQL-структура и данные передаются отдельно, что исключает их смешивание и интерпретацию данных как SQL-команд.

### Ответ 1:
`%` - это wildcard символ в SQL LIKE:
- `%текст` - заканчивается на "текст"
- `текст%` - начинается на "текст"
- `%текст%` - содержит "текст" в любом месте

Используем `%текст%` для поиска подстроки в названии фильма.

### Ответ 2:
**PreparedStatement:**
- Предварительно компилирует SQL запрос
- Использует параметры (?) вместо конкатенации строк
- Защищает от SQL Injection
- Может повторно использоваться с разными параметрами
- Лучшая производительность при многократном выполнении

**SQL Injection пример:**
```java
// Опасно с Statement:
String input = "' OR '1'='1";
stmt.execute("SELECT * FROM users WHERE name = '" + input + "'");
// Выполнится: SELECT * FROM users WHERE name = '' OR '1'='1'
// Вернет все записи!

// Безопасно с PreparedStatement:
pstmt = conn.prepareStatement("SELECT * FROM users WHERE name = ?");
pstmt.setString(1, input);
// Ищет пользователя с именем "' OR '1'='1" (которого нет)
```
